# AquaSync-releases

AquaSync release installers and the updater's `latest.json` (no source).

AquaSync is a Windows 11 desktop app that manages aquariums and their smart equipment (EHEIM Digital, Chihiros lights
and dosing pumps, the Energenie EG-PMS2 power strip and Tuya / Smart Life power strips) from one window.
